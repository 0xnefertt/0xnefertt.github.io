이 프로젝트는 개인 블로그를 Astro 중심 구조로 정리하고 운영 자동화를 구성하는 작업입니다.

## Why I built it

개인 블로그, 공부 기록, 투자/개발 메모, CV, 프로젝트 기록을 흩어지지 않게 한곳에서 운영하고 싶었습니다. 단순히 글을 올리는 공간이 아니라, 시간이 지나도 내 작업과 생각의 흐름을 추적할 수 있는 개인 플랫폼을 목표로 했습니다.

## Goals

- 카테고리 기반 포스트 구조 유지
- 읽기 쉬운 포스트 페이지 구성
- GitHub Actions 기반 정적 배포

## Current focus

- 글 작성 스캐폴딩 개선
- CV 페이지 데이터/문서 정리
- 내비게이션 접근성 개선

## Next steps

- 프로젝트별 상세 페이지를 케이스 스터디 형태로 정리
- 포스트 검색과 카테고리 탐색 경험 개선
- CV, repositories, projects 사이의 연결 강화
