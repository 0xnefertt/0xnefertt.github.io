4. 외부 서비스와 정보 공유

사이트 운영을 위해 다음 서비스가 정보를 독립적으로 처리할 수 있습니다.

  • Google Analytics: 방문 통계와 콘텐츠 이용 분석. 자세한 내용은 Google 개인정보처리방침을 참고하세요.
  • Google AdSense: Google과 제3자 광고 사업자가 이전 방문 기록 등을 바탕으로 광고를 제공할 수 있습니다. Google의 광고 쿠키는 맞춤 광고 제공과 측정에 사용될 수 있습니다.
  • GitHub Pages: 사이트 호스팅과 보안·운영 로그 처리. 자세한 내용은 GitHub 개인정보처리방침 을 참고하세요.
  • Giscus/GitHub Discussions: 댓글 기능이 활성화된 페이지에서 GitHub 계정으로 댓글을 남길 때 GitHub와 Giscus의 정책이 적용됩니다. 사이트는 GitHub 비밀번호를 수집하지 않습니다.
  • Open-Meteo 및 Frankfurter: 홈 화면의 날씨와 환율 정보를 제공하기 위해 방문자의 브라우저가 해당 API에 직접 요청할 수 있습니다.

운영자는 이메일로 직접 받은 개인정보를 판매하지 않습니다. 다만 광고·분석·호스팅 제공자는 각자의 정책과 방문자의 설정에 따라 정보를 처리할 수 있습니다.

5. 방문자의 선택과 거부 방법

  • 브라우저 설정에서 쿠키를 차단하거나 삭제할 수 있습니다. 일부 설정 저장과 광고 기능이 제한될 수 있습니다.
  • Google 태그에는 Consent Mode v2의 기본 거부 상태가 먼저 적용됩니다. Google 인증 CMP 메시지가 게시된 지역에서는 해당 메시지를 통해 선택이 전달되며, 동의하지 않은 저장·개인화 목적은 거부 상태를 유지합니다.
  • Google 광고 설정에서 맞춤 광고를 관리하거나 해제할 수 있습니다.
  • Google Analytics 차단 브라우저 부가기능을 사용할 수 있습니다.
  • 일부 제3자 광고 사업자의 맞춤 광고는 AboutAds 선택 도구에서 관리할 수 있습니다.

지역별 법률과 동의 신호에 따라 개인 맞춤 광고 또는 분석 기능이 제한될 수 있습니다. Google의 동의 메시지가 표시되는 지역에서는 메시지 안에서 동의를 거부하거나 세부 목적을 선택할 수 있습니다.
