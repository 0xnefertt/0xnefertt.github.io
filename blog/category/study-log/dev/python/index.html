Variables

Unlike JavaScript, there are no keywords such as let, const, or var. You simply write the variable name.

x = 10
y = 20
z = x + y
print(z)  # 30

Conditional Statements

Instead of {}, indentation separates code blocks.

age = 18

if age >= 18:
    print("You are an adult.")
elif age >= 13:
    print("You are a teenager.")
else:
    print("You are a minor.")

Comparison Operators

  • ==: equal to
  • !=: not equal to
  • <: less than
  • >: greater than
  • <=: less than or equal to
  • >=: greater than or equal to
  • and: logical AND
  • or: logical OR
  • not: logical NOT

Loops (for, while)

For loops are commonly used in Python and can iterate over various data structures, including lists, dictionaries, and sets. You can also use while loops, but for loops are more concise and easier to read. There is no do…while loop.

# for loop
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4
# Iterate over a list
fruits = ["apple", "banana", "orange"]
for fruit in fruits:
    print(fruit)
# apple
# banana
# orange
# Iterate over a dictionary
person = {"name": "Alice", "age": 30, "city": "Seoul"}
for key, value in person.items():
    print(f"{key}: {value}")
# name: Alice
# age: 30
# city: Seoul
# List comprehension
squares = [x**2 for x in range(10)]
print(squares)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
# Dictionary comprehension
squared_dict = {x: x**2 for x in range(5)}
print(squared_dict)  # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
# Set comprehension
squared_set = {x**2 for x in range(5)}
print(squared_set)  # {0, 1, 4, 9, 16}
# Generator expression
squared_gen = (x**2 for x in range(5))
for square in squared_gen:
    print(square)  # 0, 1, 4, 9, 16
# while loop
count = 0
while count < 5:
    print(count)  # 0, 1, 2, 3, 4
    count += 1
# Infinite loop
while True:
    response = input("Enter 'exit' to quit: ")
    if response == "exit":
        break

break, continue

  • break: terminates the loop immediately.
  • continue: skips the current iteration and moves to the next one.
for i in range(10):
    if i == 5:
        break  # End the loop when i is 5
    print(i)  # 0, 1, 2, 3, 4

Functions

Functions are defined with the def keyword. A function can accept input values, or arguments, through parameters, perform a particular task, and return a result.

def greet(name):
return f"Hello, {name}!"
def add(a, b):
    return a + b
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)
def fibonacci(n):
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fibonacci(n - 1) + fibonacci(n - 2)

Lists

Lists are defined with square brackets [] and can contain various data types. Lists are mutable, so you can add, remove, and modify their elements.

fruits = ["apple", "banana", "orange"]
print(fruits[0])  # apple
print(fruits[1])  # banana
print(fruits[2])  # orange
print(fruits[-1])  # orange (the last element)

There are various list methods, including append, insert, remove, pop, clear, sort, and reverse.

fruits.append("grape")  # Add an element to the end of the list
fruits.insert(1, "kiwi")  # Insert an element at index 1
fruits.remove("banana")  # Remove a particular element
last_fruit = fruits.pop()  # Remove and return the last element
fruits.clear()  # Empty the list
fruits.sort()  # Sort the list
fruits.reverse()  # Reverse the list
fruits.slice(1, 3)  # Return the elements at indices 1 through 2

You can create lists concisely using list comprehensions.

Dictionaries

Dictionaries are defined with curly braces {} and store data as key-value pairs. Dictionaries are mutable, so you can add, remove, and modify their elements.

person = {"name": "Alice", "age": 30, "city": "Seoul"}
print(person["name"])  # Alice
print(person["age"])   # 30
print(person["city"])  # Seoul

Dictionary methods include keys, values, items, get, and pop.

keys = person.keys()  # Return all keys in the dictionary
values = person.values()  # Return all values in the dictionary
items = person.items()  # Return all key-value pairs in the dictionary
age = person.get("age")  # Return the value associated with the key
removed_value = person.pop("city")  # Remove and return a particular key-value pair

Working with Strings

Strings can be defined with single quotes ' or double quotes ". Strings are immutable and can be manipulated through various methods.

greeting = "Hello, World!"
print(greeting.upper())  # "HELLO, WORLD!"
print(greeting.lower())  # "hello, world!"
print(greeting.replace("World", "Python"))  # "Hello, Python!"
print(greeting.split(", "))  # ["Hello", "World!"]
print(greeting.strip("!"))  # "Hello, World"
print(greeting.strip()) # "Hello, World!" (remove whitespace from both ends)
print(greeting.join(["Goodbye", "World!"]))  # "GoodbyeWorld!"
### in is used as an operator to check whether a particular substring exists in a string.
title = "Coding in Python"
if ("Coding" in title):
    print("The title contains 'Coding'.")
else:
    print("The title does not contain 'Coding'.")
file_path = "/path/to/file.txt"

for file in files:
    if file.endswitch(".pdf");
        print("This is a pdf file." )
    elif file.endswitch(".txt");
        print("This is a text file.")
    else:
        print("Unknown file format.")
name = "Alice"
greeting = f"Hello, {name}!"  # A string using an f-string
print(greeting)  # "Hello, Alice!"

Reading and Writing Files

Use the open() function to read and write files. You must specify a mode when opening a file: typically 'r' for reading, 'w' for writing, and 'a' for appending.

# Write a file
with open("example.txt", "w") as file:
    file.write("Hello, World!\n")
    file.write("This is a sample file.\n")
# Read a file
with open("example.txt", "r") as file:
    content = file.read()
    print(content)
# Append to a file (use "a" mode to add below the existing content while preserving it)
with open("example.txt", "a") as file:
    file.write("This line is added to the file.\n")

Exception Handling

Exceptions are handled using try and except blocks. Put code that may raise an exception in the try block, and the code to run when an exception occurs in the except block.

try:
    num = int("abc")
    print(num)
except ValuError:
    print("Cannot convert this to a number.")

Common Exception Types

ExceptionMeaning
ValueErrorInvalid value
TypeErrorIncorrect type
IndexErrorList index out of range
KeyErrorAccessing a missing dictionary key
ZeroDivisionErrorDivision by zero
FileNotFoundErrorFile does not exist

There is also else.

try:
    num = int("123") # Attempt
except ValueError:
    print("Conversion failed") # Run on failure
else:
    print("Conversion succeeded:", num) # Run on success

There is also finally. It always runs, whether the operation succeeds or fails.

try:
    num = int("123")
except ValueError:
    print("Conversion failed")
finally:
    print("Always runs")

raise lets you trigger an error yourself.

age = -1

if (age < 0):
    raise ValueError("Age cannot be negative")

# Result
# ValueError: Age cannot be negative

Importing Other Functionality (import / module)

In Python, each .py file is a module, and import is used to bring its functions, variables, classes, and other contents into another file.

For example:

project/
├── main.py
└── calculator.py
# calculator.py
def add (a,b):
    return a+b

def sub (a,b):
    return a-b

Here, calculator.py is a module.

# main.py
import calculator

print(calculator.add(1,2))
print(calculator.sub(1,2))

Here, import calculator imports the module from the calculator.py file.

Not just functions, but variables are part of modules too. Functions, variables, and classes written in a file basically become attributes of the module.

Unlike JS/TS, Python has no export keyword.

Working with File Paths (pathlib)

A library that works with file paths as Path objects rather than strings.

When writing a program that reads or saves files, it is used to specify reliably exactly where the file being handled is located.

For example: reading CSV files, reading JSON configuration files, saving image files, creating log files, saving scraped data, organizing uploaded files, loading documents for AI/RAG, and creating backups.

from pathlib import Path

path = Path("data/user.txt")

print(path)
# Output
# data/user.txt

print(Path.cwd())       # Check the current working directory (where the terminal command runs)
print(Path(__file__))   # Check the location of the currently running file
print(Path(__file__).resoleve())    # Usually converted to an absolute path for use

# Practical version
BASE_DIR = Path(__file__).resolve().parent # Set BASE_DIR to the folder containing the current file.

print(path.is_file())          # Check whether it is a file
print(path.is_dir())           # Check whether it is a folder

folder = Path("data")
folder.mkdir()                  # Create a folder

# Practical version
folder.mkdir(exist_ok=True)     # Create it without raising an error if it already exists

print(path.name)    # Full filename
print(path.stem)    # Name without the extension
print(path.suffix)  # Extension
print(path.parent)  # Parent folder

Relative and absolute paths

  • Relative path: a path relative to the current working directory.
  • Absolute path: the complete path starting from the computer’s root.

package / pip / virtual environments / uv

External libraries, excluding built-in libraries such as json, pathlib, and math, are called packages.

package = a collection of Python functionality created by others, or a library.

  • requests = HTTP requests
  • fastapi = backend API server
  • pandas = data analysis
  • numpy = numerical computation
  • python-dotenv = reading .env environment variables
  • pytest = testing

pip is a tool for installing Python packages, like npm install in Node.js.

# pip install requests
python -m pip install requests

import requests

response = requests.get("https://example.com")
print(response.status_code)

Virtual environments were introduced to configure package versions independently for each directory or server. venv = a Python environment dedicated to a project.

mkdir python-practice
cd python-practice
python3 -m venv .venv

# python-practice/
# └── .venv/

# Activate the virtual environment
source .venv/bin/activate
# (.venv) python-practice % python3 -m pip install requests

# Deactivate the virtual environment
deactivate

When someone else receives your project, they do not know which packages to install. That is why the installation list is written in a file called requirements.txt.

python3 -m pip install -r requirements.txt

requirements.txt manages only the package list.

A project has more to manage than its package list: its name, version, Python version, dependencies, test settings, linter settings, formatter settings, build settings, and so on.

A common modern approach is to put all of these in one file, pyproject.toml.

pyproject.toml (=package.json)

[project]
name = "python-practice"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = [
    "requests"
    "python-dotenv"
]

uv is a tool that is widely used these days.

uv = a tool that makes managing venv + pip + pyproject.toml + lock files easier.

uv init python-practice
cd python-practice

uv add requests
uv run python main.py

sqlite3

A local, file-based database included with Python. No external library installation is needed.

It stores data in a single .db file without needing to run a separate server.

# A typical structure
# python-data-practice/
# ├── main.py
# └── data/
#    └── app.db

import sqlite3
from pathlib import Path

data_dir = Path("data")
data_dir.mkdir(exist_ok=True)

db_path = data_dir / "app.db"

connection = sqlite3.connect(db_path)
# Use a cursor to send SQL commands to the database.
cursor = connection.cursor()

# Execute SQL
connection.commit()
connection.close()

# Create a table
cursor.execute("""
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    city TEXT NOT NULL,
    age INTEGER
)
""")

# Insert data
cursor.execute(
    "INSERT INTO users (name, city, age) VALUES (?, ?, ?)",
    ("nefer", "vancouver", 20)
)

# Query data
cursor.execute("SELECT * FROM users WHERE city = ?", ("vancouver"),)
rows = cursor.fetchall()
print(rows)

# Update and delete data
cursor.execute("""
UPDATE users
SET age = ?
WHERE name = ?
""", (30, "secret"))

connection.commit()

cursor.execute("""
DELETE FROM users
WHERE name = ?
""", ("secret",))
connection.commit()

class

A class is a blueprint that groups related data and functions together.

class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"My name is {self.name} and I am {self.age} years old."

user = User("Yona", 30)

print(user.name)
print(user.age)
print(user.introduce())
  • class = a blueprint
  • instance/object = an actual item made from the blueprint
  • attribute = a value held by an object
# This creates two objects from the User blueprint; user1 and user2 are different objects.
user1 = User()
user2 = User()

__init__ is the initialization function.

self is the object itself.

The advantage of classes is that you can create multiple objects with the same structure.

Special methods you should know when working with classes (double underscore methods, or dunder methods)

  • __repr__: An object representation for developers. Used to create a readable string for print(obj) or repr(obj). It must return a string.
  • __str__: A string representation for users. Preferred by str(obj) and print(obj). If absent, __repr__ is used instead.
  • __eq__: Defines the criteria for obj1 == obj2. You can decide whether objects with equal values should be considered equal.
  • __hash__: Defines the hash value needed to put an object in a set or use it as a dict key. Be careful with hashing if you define __eq__ yourself.
  • __len__: Enables len(obj).
  • __getitem__: Enables obj[index].
  • __contains__: Enables value in obj.
  • __lt__: Defines the criteria for obj1 < obj2. Related to sorting.
class Product:
    def __init__(self, name, price, quantity):
        self.name = name
        self.price = price
        self.quantity = quantity

    def total_price(self):
        return self.price * self.quantity

    def __repr__(self):
        return (
            f"Product("
            f"name={self.name!r}, "
            f"price={self.price!r}, "
            f"quantity={self.quantity!r}"
            f")"
        )

    def __eq__(self, other):
        if not isinstance(other, Product):
            return NotImplemented

        return (
            self.name == other.name
            and self.price == other.price
            and self.quantity == other.quantity
        )

product1 = Product("Apple", 2, 5)
product2 = Product("Apple", 2, 5)
product3 = Product("Banana", 1, 10)

print(product1)
print(product1.total_price())

print(product1 == product2)
print(product1 == product3)
print(product1 is product2)

type hints / dataclass / project structure

dataclass is syntax that makes creating classes to hold data easier. It automatically generates __init__, __repr__, __eq__, and other methods.

from dataclasses import dataclass

@dataclass
class Product:
    name: str
    price: int
    quantity: int

    def total_price(self):
        return self.price * self.quantity
# These are type hints.
name: str
age: int
