**C**

c 에서는 string이란 타입은 존재하지 않는다. "char \*변수명" 이 맞다.

make filename 명령어는 clang "filename.c" -o "program\_name" -l "libraryname" 을 의미한다.

c에서 main(int argc, char \*argv\[\]) 는 프로그램을 실행할 때(./filename), 함께 입력한 인자를 받는다는 의미이다.

int main(void)는 반환값이 없다는 뜻. return 이 없어도 된다.

return 0 은 정상, return 1 은 오류 있음

함수를 사용하기 전에 프로토타입을 알려줘야한다.

"sizeof" 는 해당 타입이 몇 byte를 사용하는지 알려준다.

애스터리스크(\*)

malloc, realloc, free

Pass by value: 기본적으로 값을 복사해서 함수에 전달한다.

struct 는 여러 데이터를 하나로 묶어서 하나의 타입으로 만든다. typedef struct p; 사용은 p.name ="martin", p.age=22; 이런식으로.

**배열(Array)**

int number\[3\];

배열의 인덱스는 0부터 시작한다.

배열은 같은 자료형의 값들을 저장한다.

문자열은 char 배열로 표현되고, 해당 배열의 마지막은 "NULL (\\0)" 이 들어간다.

배열은 메모리에 연속해서 저장된다.

배열 이름은 대부분의 상황에서 배열의 첫 번째 원소를 가리키는 포인터처럼 변환된다.

**알고리즘**

1\. Linear Search: 처음부터 하나씩 확인한다. **O (n)**

2\. Binary Search: 정렬된 배열에서 가운데 값을 확인한다. **O (log n)**

**BigO 빠른 순: O(1) > O(log n) > O(n) > O(n log n) > O(n^2)**

3\. Selection Sort: 가장 작은 값을 찾아 앞쪽에 배치한다. **O (n^2)**

4\. Bubble Sort: 옆의 값끼리 비교해서 큰 값을 뒤로 보낸다. **O (n^2)**

5\. Merge Sort: 배열을 계속 반으로 나눈 뒤 정렬하면서 합친다. **O (n log n)**
