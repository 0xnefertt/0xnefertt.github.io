**Variables**

The name of a space used to store a value is called a “variable.”

int, string, float, double, char, and bool are types.

A const value that does not change is called a “constant.”

**Conditionals**

if

else if

else

**Loops**

for

while

do while

**Functions**

input → \[**“function”**\] → output

Likewise, in a computer: source code → \[**“compiler”**\] → machine code

**C**

C does not have a type called string. “char \*variable_name” is the correct form.

The command make filename means clang "filename.c" -o "program\_name" -l "libraryname".

In C, main(int argc, char \*argv\[\]) means that the program receives arguments entered alongside its invocation (./filename).

int main(void) means there is no return value. A return statement is not required.

return 0 means normal completion; return 1 means an error.

A function’s prototype must be declared before using it.

“sizeof” tells you how many bytes a type uses.

Ampersand (&)

Asterisk (\*)

malloc, realloc, free

Pass by value: By default, a value is copied and passed to a function.

struct groups several pieces of data into one type. typedef struct p; can be used like p.name ="martin", p.age=22;.

**Arrays**

int number\[3\];

Array indexes start at 0.

An array stores values of the same data type.

A string is represented as a char array, ending with “NULL (\\0).”

Arrays are stored contiguously in memory.

In most situations, an array name is converted into something like a pointer to its first element.

**Algorithms**

1\. Linear Search: Check each item one by one from the beginning. **O(n)**

2\. Binary Search: Check the middle value in a sorted array. **O(log n)**

**Big O, from fastest: O(1) > O(log n) > O(n) > O(n log n) > O(n^2)**

3\. Selection Sort: Find the smallest value and place it at the front. **O(n^2)**

4\. Bubble Sort: Compare adjacent values and move the larger one toward the end. **O(n^2)**

5\. Merge Sort: Keep dividing the array in half, then merge the parts while sorting them. **O(n log n)**
