## Variables

In Rust, variables do not change by default. They are immutable.

To change one, you need to declare it with `let mut`.

```rust
let mut count = 3;
count = 4;
```

However, Rust also has cases where values are declared with `const`.

Settings, sizes, and limits that must not change are declared with `const`.

```rust
// Compile-time constant
const COUNT: u64 = 3;
```

## Types

- bool = true/false
- u64 = a large integer without negative values
- i64 = an integer that can be negative
- f64 = a floating-point number
- &str = a fixed string slice
- string = a modifiable string

```rust
let num: u64 = 1_000_000_000;
let fnum: f64 = 12.5;

let fixed: &str = "solana";

let mut name: String = String::from("solana");
name.push_str(" chain"); // solana chain
```

Once a type is set, it does not change either.

However, you can create a new binding with the same name by using let again. This is called shadowing.

```rust
let amount = "42";  // String
let amount: u64 = amount.parse().unwrap(); // u64
```

## Functions

```rust
fn add(a: u64, b: u64) -> u64 {
  a + b
}

fn is_adult(age: u8) -> bool {
  return age >= 18;
}

// If there is no return value, '->' can be omitted.
fn log_message() {
  println!("done")
}

// A final expression followed by `;` does not return a value.
fn set_count(count: &mut u64) {
  *count = 10;
}
```

## struct

```rust
struct User {
  name: String,
  age: u8,
}

let user = User {
  name: String::from("Alice"),
  age: 20,
}

println("{}", user.name)
println("{}", user.age)
```

## impl

```rust
struct Counter {
  count: u64,
}

// Attach functions/methods to a struct.
// The struct and impl names must match.
impl Counter {
  fn new() -> Self {
    Self {count: 0}
  }

  fn increment(&mut self) {
    self.count += 1;
  }

  fn get_count(&self) -> u64 {
    self.count
  }
}

fn main() {
  let mut counter = Counter::new();

  counter.increment();

  println!("{}", counter.get_counter());
}
```

- `impl` = attaches functions/methods to a `struct`
- `&self` = read
- `&mut` self = modify
- `self` = take ownership
- `Self` = the current type
- `new()` = the conventional constructor name
- `Counter::new()` = call a function associated with a type
- `counter.increment()` = call a method associated with a value
