> 이 글은 2026년 7월 22일 기준의 일반적인 정보이며 법률 자문이 아닙니다. 직종, 단체협약, 연방 규제 사업장, averaging agreement 등에 따라 다른 규칙이 적용될 수 있습니다.

BC에서 일할 때는 먼저 본인이 **employee인지 independent contractor인지** 확인하는 것이 중요하다. 계약서에 contractor라고 적혀 있다는 사실만으로 지위가 확정되는 것은 아니며, 실제 업무 관계를 기준으로 판단될 수 있다. BC Employment Standards Act는 일반적으로 employee에게 적용되고 independent contractor에게는 적용되지 않는다.

제일 중요한건 고용 형태이다.

employee인지 contractor인지에 따라 최저임금, overtime, vacation pay 같은 보호의 적용 여부가 달라질 수 있기 때문이다.

Independent contractor는 일반적으로 자신의 세금과 CPP를 직접 처리한다. EI는 employee와 같은 방식으로 자동 적용되지 않으며, 자영업자를 위한 EI 특별 혜택은 별도 등록과 조건이 있다.

직원으로 들어갈 때는 Offer Letter + Employment Agreement.

계약직으로 일할 때는 Independent Contractor Agreement / Service Agreement.

직원이라면 full-time, part-time, temporary, permanent라는 명칭만으로 기본 보호가 사라지지는 않는다. 다만 관리자와 일부 직종에는 예외 규정이 있다.

두번째는 임금 정보이다.

- Minimum wage = 최저시급

  주마다 다르다.

- Pay period = 임금 계산 기간. BC에서는 일반적으로 최소 월 2회 지급해야 하고 pay period는 16일을 넘을 수 없다.

- Paystub = 세전임금

- Tips = 팁

- Final pay = 퇴사/해고 후 마지막 임금 시점

- Record keeping = 근무 시간

BC의 일반 규칙에서는 <strong>하루 8시간 초과</strong> 또는 <strong>주 40시간 초과</strong> 근무에 overtime pay가 적용된다.

- Daily overtime (하루 8시간 초과) / Weekly overtime (주 40시간 초과)

- Double time (하루 12시간 초과 시)

- Split shift (하루 근무가 쪼개지는 경우)

- Meal break (식사시간/휴게시간)

part-time 이나 full-time은 동일하다.

다음으로 알고 있어야하는 정보는 Vacation pay (휴가비)와 Holiday pay (공휴일 페이) 이다.

BC에서는 근무 5일 이후 일반적으로 총 임금의 최소 4%에 해당하는 vacation pay가 발생하며, 5년 연속 근무를 마친 뒤에는 최소 6%가 적용된다.

**급여 관련**

캐나다/BC에서 연봉협상 자체는 회사의 법적 의무가 아니다. 회사가 매년 반드시 연봉협상 자리를 만들어야 한다거나, 물가상승률만큼 반드시 올려줘야한다는 법은 없다. 그러나 최저임금이 인상이 되는 경우 / 고용계약서에 인상을 약속한 경우 / 역할이 바뀌며 새 임금 합의가 있는 경우 / 회사 정책 등에 의해서는 조정이 의무가 될 수는 있다. 정리하자면, 연봉 인상은 법보다는 협상과 시장가격의 영역이다. 권리가 아니라 협상이다.

반대로 임금이나 근무시간의 중대한 일방적 변경은 계약과 사실관계에 따라 constructive dismissal 쟁점이 될 수 있다. 이는 개별 판단이 필요한 영역이므로 Employment Standards Branch 또는 employment lawyer에게 확인하는 편이 안전하다.

정리

| 문제                                   | 1차 문의처                        | 추가 문의처            |
| -------------------------------------- | --------------------------------- | ---------------------- |
| 임금 체불, vacation pay, overtime 문제 | BC Employment Standards Branch    |                        |
| EI 신청/거절/ROE 문제                  | Service Canada                    |                        |
| 일하다 다침                            | WorkSafeBC                        |                        |
| 차별/인권침해                          | BC Human Rights Tribunal / Clinic |                        |
| 노조 있는 직장 문제                    | Union rep                         | Labour Relations Board |
| 해고 보상, 계약서, severance           | Employment lawyer                 |                        |
| 세금 관련                              | CRA                               |                        |

아무쪼록 문제가 생기면 제출할 증거 문서가 중요하다.
