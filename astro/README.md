# Astro App

This directory contains the main Astro application for this repository.

## Install

From repository root (recommended):

```bash
npm run setup
```

Or from this directory only:

```bash
npm install
```

## Run

From repository root:

```bash
npm run serve
```

Or directly here:

```bash
npm run dev
```

## Build

From repository root:

```bash
npm run build
```

Or directly here:

```bash
npm run build
```

Build output: `astro/dist/`

## Content sources

Astro collections read content from repository root:

- `_pages/`
- `_posts/`
- `_projects/`
- `_news/`
- `_books/`
