회사를 알아볼 때나 경제⋅시사 뉴스들을 보다보면 어려운 용어들이 종종 나온다.

들어본 것 같은데 헷갈리는게 많아 정리하고자 글을 작성하게 되었다.

(챗지피티의 도움을 받아 작성하는 중..)

이 또한 많이 보다보면 익숙해질거라고 믿고 있다.

* 매출액 = 얼마나 팔았나 = 총 수입

* 매출원가 = 물건 원가

* 매출총이익 = 제품 자체에서 남긴 돈 = 매출액 - 매출원가

* 판매관리비 = 회사 운영비(급여, 광고비, 임대료, 출장비 등)

* 영업이익 = 본업으로 번 이익

* 영업손실 = 영업이익이 마이너스

* 세전이익 = 세금 내기 전 최종 이익

* 당기순이익 = 세금까지 모두 반영한 최종 이익

* 당기순손실 = 최종적으로 손해

* 영업이익률 = 영업이익 / 매출

* 순이익률 = 순이익 / 매출

예를 들어 매출 100억 → 영업이익 10억 → 순이익 6억 이다.

100억치 팔고 본업에서 10억을 벌었으며 이자⋅세금 등을 반영한 뒤 최종 6억이 남았다는 뜻이다.

* 흑자 = 돈 남김

* 적자 = 돈 잃음

영업이익과 순이익

* 영업외수익 = 본업 외에서 번 돈

* 영업외비용 = 본업 외에서 발생한 비용

* 이자수익 = 예금 등에 붙은 이자

* 이자비용 = 대출 등의 이자

* 환차익 = 환율 움직임으로 번 돈

* 환차손 = 환율 움직임으로 잃은 돈

* 외환차익/손실 = 외화 거래에서 생긴 손익

* 유형자산처분이익 = 건물⋅기계 등을 팔아 생긴 이익

* 투자자산처분이익 = 투자자산을 팔아 생긴 이익

* 손상차손 = 자산 가치가 크게 떨어졌다고 회계에 반영한 손실

* 법인세비용 = 회사가 내는 소득세 성격의 세금

영업이익이 30억인데 순이익이 5억밖에 안된다 => 이자, 환손실, 세금, 일회성 손실 등이 컸는지 확인한다. 그 반대로 영업이익이 30억인데 순이익이 70억이면 부동산 매각이나 투자이익처럼 본업 밖에서 큰 이익이 발생했을 가능성이 있다.

회사가 건재한가?

* 자산 = 회사가 가진 경제적 가치 전체(부채 + 자본)

* 부채 = 회사가 갚아야할 것 = 빚

* 자본 = 자산 - 부채

* 자본금 = 주주들이 처음 투자한 기본 자금

* 이익잉여금 = 회사에 쌓아놓은 돈 = 누적된 이익

* 부채비율 = 부채 / 자본

* 자기자본비율 = 자본 / 자산

* 유동자산 = 1년 내 현금화 가능한 자산(현금, 매출채권, 재고 등)

* 유동부채 = 1년 안에 갚아야 하는 부채 = 단기 빚

* 유동비율 = 유동자산/유동부채

* 차입금 = 금융기관 등에서 빌린 돈 = 대출

* 순차입금 = 차입금 - 현금성 자산

예를들어 회사가 자산 100억을 가지고 있는데 빚이 30억이면 자기 돈인 자본은 70억이다.

주식에서 등장하는 용어들

* 시가총액 = 현재 주가 x 발행주식 수

* ROE = 자기자본 대비 순이익

* ROA = 회사 전체 자산 대비 얼마를 벌었는지

* PER = 주가가 회사 순이익의 몇 배에 거래되는지를 보여주는 지표

* PBR = 주가가 회사 순자산 가치의 몇 배인지 보는 지표

* EPS = 주식 한 주당 순이익

* BPS = 주식 한 주당 순자산

* 배당금 = 회사가 번 돈 중 일부를 주주에게 나눠주는 돈

* 배당수익률 = 현재 주가 대비 배당금 비율

손익계산서: 일정 기간 동안 회사가 얼마나 팔고, 얼마를 쓰고, 최종적으로 얼마를 벌거나 잃었는지 보여주는 표

재무상태표: 특정 시점에 회사가 가진 자산, 갚아야 할 부채, 실제 자기 몫인 자본이 얼마인지 보여주는 표

현금흐름표: 일정 기간 동안 현금이 어디서 들어오고 어디로 나갔는지 보여주는 표
