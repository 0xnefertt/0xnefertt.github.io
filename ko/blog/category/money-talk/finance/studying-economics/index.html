#돈 이야기

오늘은 경제에 대해서 알아보자.

경제란 사람들이 살아가는 데 필요한 물건이나 서비스를 만들고, 나누고, 쓰는 모든 활동과 그로 인해 생기는 사회적 관계를 뜻한다. 한자로는 ‘경국제민(나라를 다스리고 백성을 구하다)‘의 줄임말이다.

1. 경제활동의 3요소 = 생산, 분배, 소비

2. 경제주체 = 가계, 기업, 정부

3. 생산요소 = 노동, 토지, 자본

경제의 기본 구조는 ‘생산요소 → 생산 → 소득 분배 → 소비 → 다시 생산’이 순환적으로 이어지는 것이다 (※ 여기서 저축 →투자가 추가될 수도 있다).

4. 경제의 핵심 원리 = 희소성, 선택, 기회비용

경제학은 희소한 자원을 어떻게 효율적으로 선택하고 배분할 것인지 연구하는 학문이다.

“무엇을 생산할 것인가?”

“어떻게 생산할 것인가?”

“누구를 위해 생산할 것인가?”

5. 경제 사상

고대·중세 → 중상주의(16-18세기) → 중농주의 → 고전경제학 →사회주의·마르크스 → 한계혁명·신고전파·오스트리아 학파 → 케인스 학파 → 시카고 학파·통화주의 →현대 경제학

여기서 핵심은 각 시대마다 질문이 바뀐다는 것이다.

초기 - “돈과 상업은 도덕적으로 정당한가?”

근세 - “국가는 어떻게 부자가 되는가?”

고전경제학 이후 - “시장은 어떻게 스스로 움직이는가?”

산업혁명 이후 - “자본주의의 분배 문제는 어떻게 해결할 것인가?”

20세기 - “불황이 왔을때는 정부가 개입해야 하는가?”

현대 - “시장과 정부 중 어떤 방식이 어떤 상황에서 더 효율적인가?”

7. 미시경제학과 거시경제학

미시경제학

→ 수요·공급 → 탄력성 → 소비자 → 기업 → 시장구조 → 시장실패

거시경제학

→ GDP → 물가 → 실업 → 경기순환 → 금리 → 통화 정책 → 재정정책 → 환율 → 경제성장

8. 금융·국제경제

국제경제학

→ 비교우위 → 자유무역 → 관세·보호무역 → 환율 → 국제수지 → 자본이동 → 국제통화체제

금융경제학

→ 화폐와 금융시장 → 주식·채권 → 금리 → 위험과 수익률 → 자산가격 → 포트폴리오 → 파생상품 → 금융위기
