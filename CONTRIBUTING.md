# Contributing

Thank you for contributing.

## Pull Requests

- Keep PRs focused to one concern.
- For feature work and bug fixes, open or reference an issue first.
- Include purpose, key file changes, and local verification steps in the PR description.

## Local checks

Run these before opening a PR:

```bash
npm run format:check
npm run build
```

## Issues

Use GitHub issues for bugs and feature requests.

- Confirm the issue is not already reported.
- Use the matching issue template.
- Include clear reproduction steps for bug reports.
